## Section 3 — Purpose

**H2 ·** 当天玩得尽兴，周一依然受用。

为玩而玩的游戏，当天也许很开心，到了周一就忘得一干二净。当每项活动都紧扣一个真实的目标，例如帮助新团队建立信任，或让各部门打开话匣子，欢笑就会成为大家共同的经历，日后还会一再提起。

引导不只是带游戏，而是读懂现场气氛，带领团队朝着目标前进，让每个人不分职位、不论语言，都能参与其中。

- ✓ 读懂现场气氛，随时调整
- ✓ 人人参与，不分职位
- ✓ 以英语和华语引导
- ✓ 每个环节都总结回顾，把收获带回工作

## Section 4 — Objectives

**H2 ·** 我们围绕这些目标设计

告诉我们您想达成什么。以下是各机构常向我们提出的一些目标。

**H3 ·** 加强协作 ↓

通过需要真正配合的活动，让团队和部门之间合作得更自然。

**H3 ·** 改善沟通 ↓

在可以放心尝试的环境中，练习聆听、清楚表达和勇于发言。

**H3 ·** 新员工入职与团队融合 ↓

以英语和华语双语引导，让使用不同语言的团队都能全情投入。

**H3 ·** 领导风范 ↓

让经理们练习在众人面前领导、激励和沟通。

## Section 5 — Collaboration

**H2 ·** 加强跨团队协作

我们设计的挑战，只有跨团队、跨职级集思广益才能完成。没有人能单打独斗取胜，所以大家必须沟通、计划，并彼此信任。

总结回顾会把游戏中发生的事，与团队周一的合作方式联系起来，让这一天改变的不只是心情，还有习惯。

- ✓ 需要每位成员参与的挑战
- ✓ 跨部门混合分组
- ✓ 与实际工作挂钩的总结回顾
- ✓ 从头到尾全程引导

## Section 6 — Communication

**H2 ·** 在游戏中学会更清晰的沟通

活动会奖励用心聆听、清楚下达指示和及时确认的表现，让大家在玩的过程中察觉自己的习惯。我们让气氛保持轻松，而且每个人都刚亲身经历过，收获自然更容易记住。

适合跨职能、跨地点或跨时区合作的团队；在这类团队里，小误会往往会拖慢一切。

- ✓ 聆听与指示类游戏
- ✓ 让习惯自然显现，而非说教
- ✓ 轻松、有趣又实用
- ✓ 团队共同认可的收获

## Section 7 — Onboarding

**H2 ·** 帮助新员工和合并团队融入

对于新员工和合并后的团队，我们会刻意打散分组，给大家交谈的理由。不到一个小时，大家已经能把名字和面孔对上号，最新来的同事也有了自己的故事可以分享。

我们可以把活动安排在新员工入职日、合并启动活动或区域聚会中进行。

- ✓ 刻意混合分组
- ✓ 不会让人尴尬的破冰游戏
- ✓ 适合入职活动和团队合并
- ✓ 有需要时以双语进行

**H2 ·** 表彰员工、提振士气的团队活动

- ✓ 里程碑融入节目流程
- ✓ 真诚贴心的表彰
- ✓ 从头到尾充满活力
- ✓ 由德忠主持

## Section 10 — Leadership

**H2 ·** 提升经理的领导风范

在轻松的环境中，让领导者在团队面前担当特定角色，并就他们的表现给予简单辅导。经理们可以练习领导、激励和发言，又不必承受会议室里的压力。

适合初次带领团队的主管、公司外出活动，以及刚迎来新领导的团队。

- ✓ 让领导者担任显眼而正面的角色
- ✓ 关于个人风范的简单辅导
- ✓ 新经理可以安心练习
- ✓ 可搭配沟通辅导

## Section 18 — FAQ

**H2 ·** 团队常问的问题

**H3 ·** 在新加坡举办企业团队建设，费用是多少？

2 至 3 小时的引导式活动，每位参与者 S$88 起，通常不超过 S$128。每份方案都会根据您的团体、目标和场地报价。

**H3 ·** 你们的团队建设和一般的活动配套有什么不同？

我们从您的目标出发，而不是从活动清单出发。简单了解您的团队、人数、场地和预算后，我们会围绕您想要的成果设计活动。

**H3 ·** 你们可以接待多少人的团体？

我们根据您的人数规划活动，从单一部门到全公司活动都可以。请在询问表格中填写预计人数，我们会推荐让每个人都能投入的形式。

**H3 ·** 活动可以用英语和华语进行吗？

可以。我们的创办人德忠能以英语和华语引导和主持，让使用不同语言的团队都能自在参与。

**H3 ·** 活动在哪里进行？

可以在您的办公室、酒店或活动场地，或其他适合活动的地点进行。如果您还需要场地，我们可以通过合作伙伴网络为您推荐合适的选择。

**H3 ·** 一场活动要多长时间？

大多数引导式活动为 2 至 3 小时；公司外出活动可以更长。

**H3 ·** 团队建设可以安排在我们的 D&D 晚宴中吗？

可以。团队凝聚游戏可以融入您的公司晚宴、公司外出活动或周年庆，由专业主持人带领。

**H3 ·** 应该提前多久询问？

越早越好，尤其是年底和佳节期间，日期很快就会被订满。请在询问表格中填写您希望的日期，我们会为您确认档期。

**H3 ·** 我们会收到方案和报价吗？

会。了解您的目标和要求后，我们会为您准备量身定制的方案，包括推荐的活动内容和报价。
