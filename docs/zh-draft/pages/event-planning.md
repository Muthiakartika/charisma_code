## Section 7 — How booking works

**H2 ·** 我们的活动策划团队如何执行您的活动

每场活动都不一样，所以每个方案也不会一样。以下是我们从了解您的需求到活动当晚的整个过程。

**H3 ·** 1. 您的目标

您希望这场活动带来什么改变，或庆祝什么？我们从您想要的成果出发。

**H3 ·** 2. 您的团队

现场会有哪些人：他们的职位、语言、活力，以及彼此有多熟悉。

**H3 ·** 3. 形式与流程

我们根据您的场地、人数和日程，策划节目、流程表和时间分配。

**H3 ·** 4. 预算与后勤

我们在您的预算内寻找场地和可靠的供应商，从影音设备到摄影都包括在内。

**H3 ·** 5. 执行与总结回顾

活动当天由我们执行并上台主持，事后再与您一起回顾成果。

## Section 14 — FAQ

**H2 ·** 活动策划常见问题

**H3 ·** 在新加坡举办一场企业活动要多少钱？

这取决于人数、场地、节目和供应商。请在询问表格中告诉我们您的预算范围，我们会推荐合适的方案；每份方案都会分项列明场地、供应商和主持费用。

**H3 ·** 你们策划多大规模的活动？

从单一部门的活动，到数百位宾客参加的全公司活动都有。

**H3 ·** 你们可以帮忙寻找和预订场地吗？

可以。我们会推荐符合您人数、日期和预算的场地，并与您一起办理预订。

**H3 ·** 除了策划，你们也可以主持活动吗？

可以。我们的创办人德忠能以英语和华语担任司仪，所以策划和主持都由同一个团队负责。

**H3 ·** 你们策划家庭日吗？

是的。游戏、餐饮、司仪和后勤，一个方案全包，室内户外皆可。

**H3 ·** 你们策划公司晚宴吗？

是的。详情请参阅我们的公司晚宴策划页面，从主题到压轴大抽奖都有说明。

**H3 ·** 你们可以策划新品发布会吗？

可以。我们的新品发布会页面介绍了策划、主持、内容创作者和内容制作。

**H3 ·** 应该提前多久询问？

越早越好，尤其是年终和节庆期间，档期很快就会排满。请在询问表格中填写您的理想日期，我们会为您确认档期。

**H3 ·** 我们会收到方案和报价吗？

会的。了解您的目标和需求后，我们会为您准备量身定制的方案，附上建议的节目流程和报价。
